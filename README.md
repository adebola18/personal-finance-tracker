Personal Finance Tracker

A simple personal finance tracker built with HTML, CSS, and JavaScript. It helps users record and manage their income and expenses in one place.

Features

* Add income and expenses
* View transactions
* Calculate total income
* Calculate total expenses
* Track your current balance
* Simple and responsive interface
 Technologies Used

* HTML
* CSS
* JavaScript

 How to Use

1. Enter your income or expense details.
2. Add the transaction.
3. View your transactions and updated balance.

 Project Purpose

This project was created to practice frontend web development and JavaScript programming while building a practical personal finance application.
